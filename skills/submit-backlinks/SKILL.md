# submit-backlinks

我们的 GrokBot 外链 Bot 每天就是这么跑的。

1. 先处理昨天没做完的站，再从 [data/backlinks.csv](../../data/backlinks.csv) 挑新站，每天 8–10 条。和产品相关的分类优先，跳过 [已知走不通的站](references/known-blocked.md)。
2. 在浏览器里注册账号、提交。注册用你自己的邮箱，验证码和验证链接去收件箱取。
3. 只能用 Google / GitHub 登录、要手机号或真实身份、要付费的站，跳过，记下原因。
4. 账号密码只存加密位置，不写进文件和聊天。
5. 不登录打开公开页，确认链接能点，看一下源码里有没有 nofollow，截图留证。没复核的不算成功。
6. 每天凌晨 1 点自动开始，跑完发日报。

## 日报

- 今日成功：站点、查看链接、一句说明
- 未完成：只列今天试过没成的站，每条一句原因和下一步
- 历史积压：底部一行分类计数
- 累计数

中文沟通，结论先行。
