# 已知走不通的站

GrokBot 用自有邮箱实际跑下来，下面这些站没法自动完成。选站时直接跳过，省时间。

| 站点 | 卡在哪 |
|---|---|
| about.me | 只能用社交账号登录 |
| hashnode.com | 只能用社交账号登录 |
| indiehackers.com | 只能用 Google 注册 |
| jsitor.com | 只能用 GitHub 登录 |
| flipboard.com | 不收 agent 的邮箱，只能用 Google / Apple 登录 |
| dev.to | 不收 agent 的邮箱域名 |
| gitlab.com | 验证谜题过不去，注册后还要手机号 |
| letterboxd.com | 人机验证 |
| nekoweb.org | 注册连续报错，疑似人机验证 |
| instructables.com | 注册强制填生日 |
| bio.link | 注册后强制选付费方案 |
| beacons.ai | 必须绑定社交媒体账号 |
| weebly.com | 强制走 Square 注册 |
| direct.me | 页面要付月费才上线 |
| calameo.com | 文档描述里的网址只显示纯文本，没有可点链接 |
| tilda.cc、mastodon、sourceforge.net、artstation.com、dribbble.com、webnode.com | 试过多次走不通，已停止跟进 |

behance.net 注册时也会强制填生日。按 skill 的规矩应该跳过，清单里保留它是因为我们实际发成过。
